Project Overview

CrimeWatch Analytics is a beginner-friendly, academic Data Science and Machine Learning web application developed as a first major portfolio project for a B.Sc Data Science curriculum.

The purpose of this project is to analyze historical crime data, uncover temporal and spatial patterns, present descriptive visualizations, and estimate broad scenario risk categories using a trained Random Forest model.

Project Workflow

Crime Dataset → Data Cleaning → Exploratory Data Analysis → Feature Engineering → Random Forest ML → Flask Web App + MySQL → Safety Insights

Technology Stack

  • Backend: Python 3.13, Flask 3.1
  • Data Science: Pandas, NumPy, Scikit-learn, Joblib
  • Database: MySQL / SQLite Fail-safe
  • Frontend: HTML5, CSS3, Bootstrap 5
  • Visualization: Chart.js
  • Reporting: Microsoft Excel, Microsoft Power BI

Ethical Principles & Anti-Surveillance Guarantee

This system is strictly designed as an academic data analytics tool and explicitly rejects mass-surveillance mechanisms:

  • No Individual Profiling: The model never evaluates or predicts individuals, suspect behaviors, or demographic groups.
  • No Camera / CCTV / Facial Recognition: Analysis is strictly performed on aggregate historical incident statistics.
  • No Predictive Law Enforcement: Predictions are statistical classifications of contextual scenario attributes, not deterministic forecasts of future crimes.

System Limitations

  • Reported vs. Actual Crime: The dataset reflects reported incidents; unreported offenses cannot be accounted for by the model.
  • Synthetic Nature: The educational dataset simulates realistic urban distributions but must not be cited as official municipal law enforcement records.
  • Temporal Dynamics: Crime patterns fluctuate with policy and community changes; models require periodic retraining with fresh data.
